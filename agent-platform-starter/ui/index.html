    Credentials
    Tokens and keys for connections (GitHub, HTTP tools). They are encrypted in the SSH gateway and can't be read back, not even here: you can only replace or delete them. Agents never see them; the gateway fills them in when it makes a call and masks them in every reply and log.

    HTTP tools
    Simple API calls agents can make through the gateway: a fixed https host, a path with {placeholders}, typed parameters and an optional credential that only the gateway sees. Each tool is offered to agents whose level on http_tools (Policy page) reaches the tool's level. Private and local addresses are refused unless you allow them per tool.
